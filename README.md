# 우주마을 (SPACE VILLAGE) — 가칭

친구들과 달 기지에서 만나고, 우주를 날아다니며 과학을 배우는 3D 소셜·교육 웹 월드입니다.

지금은 **PHASE 0(기획·시안)** 단계입니다. 서버·DB·서버 로그인·멀티플레이는 아직 없습니다. 시안의 회원가입·로그인은 이 브라우저(localStorage)에만 저장되는 로컬 계정이고, 채팅은 같은 브라우저의 다른 탭끼리만 오갑니다. 기획서가 승인되면 PHASE 1을 시작합니다.

## 3D 시안 실행

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다.

```bash
cd prototype/phase0
npm ci
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
```

주소 뒤에 `?scene=moon`, `?scene=space`, `?scene=lounge`, `?scene=station`처럼 장면을 지정해 바로 열 수 있습니다. 화면 위쪽 버튼으로 PC·모바일 배치를 바꿔 볼 수 있습니다.

### 조작 (PC)

- 공통: 3D 화면의 **위치 풍선을 클릭**하면 그 앞으로 바로 이동해서 실행 (바로 앞 풍선은 E) · M 이동 메뉴(달 착륙지·정거장·우주 탐험) · Enter 채팅(보낸 사람 머리 위에 말풍선) · 1~8 감정 표현(8 물 마시기)
- 달: WASD 걷기 · Shift 깡충 달리기 · Space 점프(착지하는 순간 다시 누르면 연속 점프, 최대 4단) · 월면차(5대, 4인승): 운전 중 F 친구 태우기 · E 내리기
- 우주 탐험·우주 유영: 내 아바타로 비행 · Space 누르는 동안 상승(떼면 그 높이에 떠 있음, 최대 높이 있음) · C 하강 · Shift 부스트 · 드래그·방향키 360° 회전 · X 수평 · R 정거장으로 바로 복귀 · 우주 탐험에서는 가까이 가면 발견, 발견한 천체 클릭 또는 E로 정보
- 물 마시기: 정거장(무중력)은 물이 공처럼 둥둥, 라운지(1/6 중력)는 물방울이 천천히 떨어짐, 달 표면은 헬멧 속 음료 주머니 빨대로

### 조작 (모바일)

- 왼쪽 아래 조이스틱 · 오른쪽 아래 점프(유영·우주 탐험은 상승·하강·부스트·수평) · 오른쪽 가운데 보조 줄(채팅·감정·이동 등)
- 장소에 들어가거나 무언가를 하려면 그 위치 풍선을 탭합니다. 채팅은 보조 줄의 '채팅'으로 위쪽 창을 열고 닫습니다.

## 지켜야 할 원칙

- 멍글마을의 Oracle 서버·DB·배포 설정·운영 데이터와 완전히 분리합니다. 멍글마을 파일을 직접 참조하거나 수정하지 않습니다.
- 회원·강아지·코인·아파트 데이터는 가져오지 않습니다.
- 라이선스가 분명한 에셋만 쓰고, 출처를 `ASSET_PROVENANCE.md`에 기록합니다.
- 유료 리소스 생성, 결제, 운영 서버 배포는 사전 승인 없이 하지 않습니다.
- 클라이언트가 보낸 위치·보상 값은 서버에서 다시 검증합니다(기획서 14·15장).
