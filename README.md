# 우주마을 (SPACE VILLAGE) — 가칭

친구들과 달 기지에서 만나고, 우주를 날아다니며 과학을 배우는 3D 소셜·교육 웹 월드입니다.

지금은 **PHASE 0(기획·시안)** 단계입니다. DB·서버 로그인은 아직 없고, 시안의 회원가입·로그인은 숨겼습니다. 시작 화면의 **우주로 떠나기**를 누르고 닉네임·아바타를 정하면 되고, 닉네임·아바타·진행 기록은 이 브라우저(localStorage)에만 저장됩니다. 실시간 서버(`server/`)는 코드와 부하 테스트까지 했고 **배포하지 않았습니다.** 기획서가 승인되면 PHASE 1을 시작합니다.

## 3D 시안 실행

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다.

```bash
cd prototype/phase0
npm ci
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
```

주소 뒤에 `?scene=moon`, `?scene=space`, `?scene=lounge`, `?scene=station`처럼 장면을 지정해 바로 열 수 있습니다. 화면 위쪽 버튼으로 PC·모바일 배치를 바꿔 볼 수 있습니다.

### 조작 (PC)

- 공통: 3D 화면의 **위치 풍선을 클릭**하면 그 앞으로 바로 이동해서 실행 (바로 앞 풍선은 E) · 오른쪽 위 **장소 드롭다운**(지금 위치 표시, 고르면 바로 이동) · M 이동 메뉴(달 착륙지·라운지·정거장·우주 탐험) · Enter 채팅(보낸 사람 머리 위에 말풍선) · 1~8 감정 표현(8 물 마시기) · 아래 조작 안내는 ×로 닫고 '⌨ 조작 안내'로 다시 열기
- 달: WASD 걷기 · Shift 깡충 달리기 · Space 점프(착지하는 순간 다시 누르면 연속 점프, 최대 4단) · 월면차(24대, 4인승): 운전 중 F 친구 태우기 · E 내리기 · 다른 사람이 운전하는 월면차는 풍선을 눌러 빈자리에 탑승
- 우주 탐험: 내 아바타로 비행 · Space 누르는 동안 상승(떼면 그 높이에 떠 있음, 최대 높이 있음) · C 하강 · Shift 부스트 · 드래그·방향키 360° 회전 · X 수평 · R 정거장으로 바로 복귀 · 우주 탐험에서는 가까이 가면 발견, 발견한 천체 클릭 또는 E로 정보
- 물 마시기: 정거장(무중력)은 물이 공처럼 둥둥, 라운지(1/6 중력)는 물방울이 천천히 떨어짐, 달 표면은 헬멧 속 음료 주머니 빨대로

### 조작 (모바일)

- 왼쪽 아래 조이스틱 · 오른쪽 아래 점프(우주 탐험은 상승·하강·부스트·수평) · 오른쪽 가운데 보조 줄(채팅·감정·이동 등)
- 장소에 들어가거나 무언가를 하려면 그 위치 풍선을 탭합니다. 채팅은 보조 줄의 '채팅'으로 창을 열고 직접 입력합니다.

## 멀티플레이 (직접 채팅)

같은 공간(달 착륙지·정거장·라운지·우주 탐험)에 있는 사람끼리 아바타·움직임·감정 표현·월면차 탑승·채팅이 실시간으로 보입니다. 채팅은 직접 입력하고(최대 60자), 머리 위 말풍선으로도 뜹니다. 이메일·주소·전화번호와 일부 욕설은 `(가림)`으로 바뀝니다. 연결은 두 가지입니다.

| 연결 | 누가 들어오나 | 켜는 법 |
|---|---|---|
| Claude 아티팩트 실시간 방 | 아티팩트를 공유받은 claude.ai 사용자. 공개 링크로만 연 사람은 혼자 모드 | 아티팩트에서 열면 자동 |
| 우주마을 서버 (`server/`) | 주소를 아는 누구나. 공간마다 채널 정원 30명 | 주소 뒤에 `?server=http://localhost:8787` |

```bash
cd server && npm ci && npm start         # http://localhost:8787
cd prototype/phase0 && npm run dev       # 브라우저에서 /?server=http://localhost:8787
```

아무도 없으면 NPC가 대답하고, 다른 사람이 있으면 NPC는 조용합니다. 서버는 위치·속도·좌석·도배를 다시 검사하고 클라이언트 값을 그대로 믿지 않습니다. 무료 호스팅에서 몇 명을 받을 수 있는지는 아직 모릅니다. 배포할 곳을 정하면 그 서버에서 `server/test/load.mjs`로 다시 측정합니다.

## 지켜야 할 원칙

- 멍글마을의 Oracle 서버·DB·배포 설정·운영 데이터와 완전히 분리합니다. 멍글마을 파일을 직접 참조하거나 수정하지 않습니다.
- 회원·강아지·코인·아파트 데이터는 가져오지 않습니다.
- 라이선스가 분명한 에셋만 쓰고, 출처를 `ASSET_PROVENANCE.md`에 기록합니다.
- 유료 리소스 생성, 결제, 운영 서버 배포는 사전 승인 없이 하지 않습니다.
- 클라이언트가 보낸 위치·보상 값은 서버에서 다시 검증합니다(기획서 14·15장).
