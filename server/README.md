# 우주마을 실시간 서버 (Socket.IO)

링크를 아는 누구나 함께 접속하는 멀티플레이용 서버입니다. **아직 어디에도 배포하지 않았습니다.** 배포(호스팅 가입·연결)는 승인을 받은 뒤 진행합니다.

지금 3D 시안의 멀티플레이는 두 가지 방법으로 붙습니다.

| 방법 | 누가 함께 들어오나 | 서버 |
|---|---|---|
| Claude 아티팩트 실시간 방 (`room`) | 아티팩트를 공유받은(초대된) claude.ai 사용자. 링크만 받은 사람은 혼자 모드 | 필요 없음 |
| 이 서버 | 링크를 아는 누구나 | 이 폴더를 배포해야 함 |

시안 주소 뒤에 `?server=https://서버주소`를 붙이면 이 서버로 접속합니다.

## 실행

Node.js 20.19 이상이 필요합니다.

```bash
cd server
npm ci
STATS_TOKEN=아무문자열 npm start          # http://localhost:8787
# 다른 터미널에서 시안 열기: http://localhost:5173/?scene=moon&server=http://localhost:8787
```

| 환경 변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8787 | 포트 |
| `CHANNEL_CAP` | 30 | 채널 정원. 차면 같은 공간의 다음 채널로 보냄 |
| `MAX_PLAYERS` | 500 | 서버 전체 최대 접속 |
| `MAX_PER_IP` | 8 | 한 IP의 최대 동시 접속 |
| `ALLOWED_ORIGINS` | (개발: 모두 허용) | 접속을 허용할 웹 주소, 쉼표로 구분. `NODE_ENV=production`이면 꼭 정해야 시작됨 |
| `STATS_TOKEN` | (없음) | 정하면 `/stats`가 켜지고, 요청 헤더 `x-stats-token`이 같아야 응답 |
| `TRUST_PROXY` | (없음) | `1`이면 `x-forwarded-for`로 IP를 셈 (프록시 뒤에서만) |

## 클라이언트를 믿지 않는 부분

- 모양·범위·길이: `packages/shared/protocol.js`의 `sanitizeState`·`sanitizeProfile`·`cleanText`로 확인합니다. 공간(존) 밖 위치는 안쪽으로 당깁니다.
- 속도: 공간별 최고 속도의 1.5배 + 0.5 m를 넘게 움직이면, 이전 위치에서 그 거리까지만 옮기고 `fix`로 알려 줍니다. 위치 풍선·이동 메뉴 같은 순간 이동은 `warp` 뒤 2초 안에만 허용합니다(1.5초에 한 번).
- 월면차 좌석: 먼저 앉은 사람이 임자이고, 찬 자리는 `seatTaken`으로 거절합니다.
- 보내는 횟수: 전체 초당 40개(순간 80), 위치 초당 15개, 채팅 초당 1개(순간 3), 입장 초당 2개. 넘으면 버리고, 1초에 30개 넘게 버려지면 연결을 끊습니다.
- 메시지 크기: 4 KB까지.
- 채팅: 욕설을 가리고, 이메일·링크·전화번호(숫자 9자리 이상)는 `(가림)`으로 바꿉니다.
- 아직 없는 것: 로그인, 신고·차단, 서버 저장(채팅 기록 없음), 보상. 보상은 이 서버와 연결하지 않았습니다.

## 부하 테스트

```bash
STATS_TOKEN=… MAX_PER_IP=2000 npm start
STATS_TOKEN=… node test/load.mjs --url http://localhost:8787 --bots 30 --secs 30
```

봇은 달 착륙지에서 0.1초마다 위치를 보내며 걷고, 20~40초에 한 번 채팅합니다. 결과는 기획서 17장과 `docs/load-test-2026-11-13.md`에 있습니다.
